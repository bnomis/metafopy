    Diagnostics¶

    Diagnostics for rma_uni fits follow metafor's functions of the same names. The examples use the BCG data:

    from metafopy import datasets, escalc, rma

dat = escalc(measure='RR', ai='tpos', bi='tneg', ci='cpos', di='cneg', data=datasets.load('dat.bcg'))
res = rma('yi', 'vi', data=dat)

    rstandard gives internally standardized residuals and rstudent externally studentized residuals (the residual of each study from a model fitted without it). Studies with absolute values above about 2 or 3 deserve a look.

    residuals takes a type: 'response' (the default, the raw residuals), 'rstandard', 'rstudent', 'pearson' (the raw residuals divided by the square root of the sampling variance plus tau^2) and 'cholesky' (the residuals decorrelated with the Cholesky factor of the marginal variance-covariance matrix). Which types a fit class allows follows metafor. na_action stands in for R's options(na.action=). weights_(type='matrix') returns the weight matrix.

    from metafopy import residuals

print(residuals(res, 'pearson'))
print(res.residuals('rstudent', na_action='exclude'))
print(res.weights_('matrix').shape)

    Influence¶

    influence computes the case deletion diagnostics of Viechtbauer and Cheung (2010), https://doi.org/10.1002/jrsm.11: externally studentized residuals, DFFITS, Cook's distances, covariance ratios, hat values, leave-one-out estimates of tau^2 and Q, and DFBETAS.

    from metafopy import influence

inf = influence(res)
print(inf)

    The last column, inf, is empty unless a study is flagged as influential (as in metafor, by the usual cutoffs). The individual diagnostics are also available as cooks_distance and dfbetas; influence(res, measure='cooks.distance'), measure='dfbetas' and measure='rstudent' return the same objects as those functions and rstudent, as in metafor. plot_infl plots them all:

    import matplotlib.pyplot

from metafopy import plot_infl

plot_infl(inf)
matplotlib.pyplot.savefig('influence.png')

    Leave-one-out and cumulative analyses¶

    leave1out refits the model leaving out each study in turn and cumul adds the studies one at a time, in their order in the data (sort the data first to cumulate by year or precision).

    from metafopy import cumul, leave1out

print(leave1out(res).estimate[:3])
print(cumul(res).estimate[:3])

    [-0.70708379 -0.6540312  -0.68555442]
[-0.88931133 -1.32500344 -1.33023415]

    Both return a result whose fields (estimate, se, ci_lb, ci_ub, tau2...) are arrays with one entry per fit, and print as a table. leave1out and cumul also work for rma_mh and rma_peto fits.

    Heterogeneity sources: Baujat and GOSH¶

    A Baujat plot (Baujat et al., 2002, https://doi.org/10.1002/sim.1221) shows which studies contribute most to the heterogeneity and to the overall result. The GOSH plot (Olkin et al., 2012, https://doi.org/10.1002/jrsm.1053) fits the model to many subsets of the studies and shows the distribution of the results. With many studies it fits a random sample of the subsets, controlled by subsets and seed.

    from metafopy import baujat, gosh, plot_gosh, set_seed

baujat(res)
set_seed(1234)
plot_gosh(gosh(res, subsets=200))

    Heteroscedastic heterogeneity¶

    The random-effects model assumes the same amount of heterogeneity, tau^2, for every study. hettest (new in metafor 5.2-1) tests this assumption, H0: tau^2_1 = ... = tau^2_k, for a model without moderators or for a vector of estimates with their sampling variances (vi=) or standard errors (sei=). The default is a score test; test='lrt' and test='wald' give a likelihood ratio and a Wald-type test, and 'ksn', 'ksx2', 'adn' and 'adx2' check the Pearson residuals with Kolmogorov-Smirnov and Anderson-Darling goodness-of-fit tests. The p-values come from a parametric bootstrap (boot=1000 samples unless you set boot= to another count), which draws from R's random number generator, so seed= gives the results of set.seed() in R. boot=False uses the chi-squared reference distribution of the three model-based tests instead.

    from metafopy import hettest

print(hettest(res, seed=1234))
print(hettest(res, test=['lrt', 'ksn'], boot=200, seed=1234))

    Test for Heteroscedastic Heterogeneity

Estimation method: Restricted maximum likelihood
Test type:         Score test
Bootstrapping:     Yes (1000/1000 iterations)

X^2(df = 12) = 2.8884, p = 0.9920

    The result holds the statistics (statistic), p-values (pval), the estimated study-specific variances (tau2i) and the bootstrapped statistics (statistic_boot). Fitted models of the classes rma_mv, rma_glmm, selmodel and location-scale models are not accepted, as in metafor.

    Variance inflation factors¶

    For meta-regression, vif reports collinearity among the moderators:

    from metafopy import vif

print(vif(rma('yi', 'vi', mods='~ ablat + year', data=dat)))

     ablat    year
1.5391  1.5391

    vif also takes rma_mv, location-scale and selmodel fits with moderators. The options are those of metafor: btt (and att for the scale part), table=True for the coefficient table, intercept=True to include the intercept, fixed=True to match a string btt literally, and, except for selmodel fits, reestimate=True and sim.
