    Selection models and location-scale models¶

    Selection models¶

    Selection models (Vevea and Hedges, 1995, https://doi.org/10.1007/BF02294384) model how the probability that a study is published depends on its p-value, and estimate the effect corrected for that selection. selmodel takes a fitted rma_uni model and a selection function type. It mirrors metafor's selmodel; see Citkowicz and Vevea (2017), https://doi.org/10.1037/met0000119, for the parametric functions.

    from metafopy import datasets, rma, selmodel

dat = datasets.load('dat.hackshaw1998')
res = rma(data=dat, method='ML')
print(selmodel(res, type='halfnorm'))

    The first part of the output is the corrected random-effects model. The test of the selection model parameters asks whether there is evidence for selection at all.

    The type can be a parametric function ('beta', 'halfnorm', 'negexp', 'logistic', 'power', 'negexppow') or a step function. Step functions need the cut points of the p-value, given as steps:

    print(selmodel(res, type='stepfun', steps=[0.025, 0.10, 0.50, 1]))

    Each row of the table is the relative probability of publication of a study with a p-value in that interval, relative to the first interval. alternative sets the direction of the one-sided test that selection is based on (default 'greater').

    Results can be plotted with plot_selmodel, which draws the estimated selection function. confint, profile, anova and predict work on a selection model fit, and the profile function takes the parallel options of metafor.

    Selection models are sensitive to the choice of function and need many studies to be estimated reliably. Use them as a sensitivity analysis. See also Publication bias.

    Location-scale models¶

    Location-scale models (Viechtbauer and Lopez-Lopez, 2022, https://doi.org/10.1002/jrsm.1562) let the amount of heterogeneity depend on moderators, so tau^2 is modelled alongside the average effect. Pass a scale formula to rma:

    from metafopy import rma

dat = datasets.load('dat.bangertdrowns2004')
res = rma('yi', 'vi', mods='~ length', scale='~ length', data=dat)
print(res)

    The location part (the average effect) and the scale part (the log of tau^2, by default) are reported separately. Use link='identity' to model tau^2 itself. The result is an RMALSResult, and predict, confint, anova (Wald and likelihood ratio tests), profile, vif, blup, ranef, rstandard and permutest work on it.

    control={'optimizer': ...} accepts the optimisers of rma.uni ('optim' with optmethod, 'nlm', 'bobyqa', 'hjk', ..., and with link='identity' also 'constrOptim', 'solnp', 'nloptr', 'constrOptim.nl'/'alabama' and 'auglag'; any other optimiser is reset to 'constrOptim' with a warning there, and the barrier optimisers cannot be used with the log link). They are mapped as for selmodel; ncpus above 1 selects 'optimParallel', but the likelihood is evaluated serially. confint(res, control={'vc.min': ..., 'vc.max': ...}) sets the interval searched for the bounds (vc_min and vc_max work too).

    from metafopy import predict

print(predict(res, newmods=[5, 25], newscale=[5, 25]))
