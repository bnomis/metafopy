    Calculate effect sizes yi and sampling variances vi (metafor's escalc).

    The metafor reference (last section) lists the measures, the arguments each one needs and the vtype options. add defaults to 1/2, except for the measures where metafor uses 0 (AS, PHI, ZPHI, RTET, ZTET, IRSD, PAS, PFT, IRS, IRFT).

    summary_escalc ¶

    summary_escalc(
    object: DataFrame,
    out_names: Sequence[str] = (
        'sei',
        'zi',
        'pval',
        'ci.lb',
        'ci.ub',
    ),
    var_names: Sequence[str] | None = None,

    replace: bool = True,
    level: float = 95,
    olim: Sequence[float] | None = None,
    digits: int | Sequence[int] | None = None,
    transf: Callable[..., Any] | None = None,
    **kwargs: Any,
) -> DataFrame

    Add standard errors, test statistics, p-values and confidence intervals to the output of escalc.

    Mirrors metafor's summary.escalc. With yi and vi the effect sizes and sampling variances, it computes sei = sqrt(vi), zi = (yi - H0) / sei, the two-sided p-value pval and the Wald-type interval yi -/+ z_crit * sei. With transf, yi and the bounds are transformed (the bounds are put in increasing order) and vi, sei, zi and pval are dropped.

    Parameters:

    Name Type Description Default
    object DataFrame

    data frame returned by escalc (or a frame with the effect sizes and sampling variances as columns).

    		 required
    out_names Sequence[str]

    names of the five new columns, in the order standard error, test statistic, p-value, lower and upper bound (default 'sei', 'zi', 'pval', 'ci.lb', 'ci.ub').

    		 ('sei', 'zi', 'pval', 'ci.lb', 'ci.ub')
    var_names Sequence[str] | None

    names of the columns with the effect sizes and the sampling variances (two names). Default None: taken from the attributes of object, else 'yi' and 'vi'.

    		 None
    H0 ArrayLike

    value of the effect under the null hypothesis for zi and pval, a scalar or one value per row (default 0).

    		 0
    append bool

    whether the new columns are appended to object (default True); otherwise only the effect sizes (and sampling variances) and the new columns are returned.

    		 True
    replace bool

    whether existing columns with the names in out_names are replaced (default True); if False only their missing values are filled in.

    		 True
    level float

    confidence level in percent, between 0 and 100 (default 95).

    		 95
    olim Sequence[float] | None

    (lower, upper) limits to which yi and the bounds are clipped; zi and pval are based on the unclipped values. Default None: no clipping.

    		 None
    digits int | Sequence[int] | None

    number of decimals used when the frame is printed; stored in attrs['digits']. Default None: the digits of object.

    		 None
    transf Callable[..., Any] | None

    function applied to the effect sizes and the bounds, for example metafopy.transf.ilogit. Default None.

    		 None
    **kwargs Any

    additional arguments passed on to transf.

    		 {}

    Returns:

    Type Description
    DataFrame

    A data frame with the columns of object and the new columns named by out_names (or yi, vi, and the new columns when
    DataFrame

    append=False). The escalc attributes (measure, slab, ni, ...) are kept, except when transf is given: the result then
    DataFrame

    does not carry measure, slab, ni and the row labels. With transf and append=False, only yi and the two bounds are returned.

    Raises:

    Type Description

    out_names or var_names or olim has the wrong length, a column is not found, level is outside 0 to 100, or transf does not return a single value for each value.

    cmicalc ¶

    cmicalc(
    mi: ArrayLike, method: bool | str = 'exact'
) -> NDArray[float64]

    Small-sample bias correction factor for standardized mean differences.

    Mirrors metafor's cmicalc. The factor c(m) of Hedges (1981, doi:10.3102/10769986006002107) multiplies a standardized mean difference to remove its small-sample bias. escalc uses it for the measures SMD, SMD1, SMDH, SMD1H, SMN, SMCC, SMCR, SMCRH, SMCRP and SMCRPH, passing its argument correct as method.

    Parameters:

    Name Type Description Default
    mi ArrayLike

    degrees of freedom m (for example n1i + n2i - 2), scalar or array-like.

    		 required
    method bool | str

    'exact' | 'approx' | True | False. 'exact' (or True, the default) uses the gamma-function form, 'approx' the approximation 1 - 3/(4m - 1), and False applies no correction (a factor of 1). Strings can be abbreviated; an empty string or None raises.

    		 'exact'

    Returns:

    Type Description
    NDArray[float64]

    Array of the factors c(m) with the shape of mi; with 'exact' or 'approx', NaN where m <= 1 (or mi is missing).

    Raises:

    Type Description
    InputError

    method is None, or a string that is not an abbreviation of 'exact' or 'approx'.

    cbind_escalc ¶

    cbind_escalc(
    *args: DataFrame | Series, **columns: Any
) -> DataFrame

    Combine data frames and further columns side by side and keep the escalc attributes.

    Mirrors metafor's cbind() for escalc objects. The names of the effect size, sampling variance, standard error, test statistic, p-value and confidence interval columns of all frames are collected (those of later frames first, as in R), digits is that of the last frame, and measure, slab and ni come from the first frame that has them. Column names are not made unique.

    Parameters:

    Name Type Description Default
    *args DataFrame | Series

    data frames (usually from escalc or summary_escalc) or named Series, all with the same number of rows.

    		 ()
    **columns Any

    further columns, named by the keyword; a vector becomes one column and a data frame has its columns prefixed with name. (unless it has just one column).

    		 {}

    Returns:

    Type Description
    DataFrame

    The combined data frame, with the columns of all arguments in order and the index of the first.

    Raises:

    Type Description
    InputError

    nothing is given, or the arguments have different numbers of rows.
    ArgumentError

    an argument is neither a data frame nor a named Series.

    rbind_escalc ¶

    rbind_escalc(*args: DataFrame) -> DataFrame

    Stack data frames on top of each other and keep the escalc attributes.

    Mirrors metafor's rbind() for escalc objects. The columns are matched by name and the attributes of the first frame (measure, digits, the names of the effect size columns, ...) are kept. ni is the concatenation of the sample sizes of all frames (missing if one has none) and slab the concatenation of the study labels made unique as metafor does (repeats get .1, .2, ...), or missing if one frame has none.

    Parameters:

    Name Type Description Default
    *args DataFrame

    the data frames to stack, usually from escalc; they must have the same columns.

    		 ()

    Returns:

    Type Description
    DataFrame

    The stacked data frame. If all frames have the default index, a fresh 0-based index is made, else the row names are made unique.

    Raises:

    Type Description
    InputError

    nothing is given, or the numbers or names of the columns differ.
    ArgumentError

    an argument is not a data frame.
