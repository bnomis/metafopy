    Fit an equal-, fixed-, random- or mixed-effects meta-analytic model.

    Mirrors metafor's rma.uni() (alias rma). The model is given either as effect sizes with their sampling variances (yi with vi or sei), as a model formula in yi ('yi ~ ablat + year', which then also supplies the moderators), as an escalc data frame, or as raw data (ai, bi, ... with measure), in which case the effect sizes are computed by escalc. Passing scale fits a location-scale model (Viechtbauer & Lopez-Lopez, 2022, doi:10.1002/jrsm.1562).

    Parameters:

    Name Type Description Default
    yi ArrayLike | str | DataFrame | None

    Observed effect sizes, as an array or the name of a column of data. May also be a model formula ('yi ~ ablat + year'; needs data; mods is then ignored with a warning and so is intercept, since the formula decides whether there is an intercept), or a data frame (taken as data; its yi and vi columns are used).

    		 None
    vi ArrayLike | str | None

    Sampling variances, as an array or a column name. A single value is used for every study.

    		 None
    sei ArrayLike | str | None

    Standard errors, as an array or a column name; their squares are used as vi. Ignored when vi is given.

    		 None
    weights ArrayLike | str | None

    Optional custom weights for the fit, as an array or a column name; negative weights raise an error. Required for method='GENQ' and 'GENQM'.

    		 None
    ai ArrayLike | str | None

    2x2 table frequencies (upper left cell). With bi, ci and di and a measure such as 'OR' or 'RR'.

    		 None
    bi ArrayLike | str | None

    2x2 table frequencies (upper right cell).

    		 None
    ci ArrayLike | str | None

    2x2 table frequencies (lower left cell).

    		 None
    di ArrayLike | str | None

    2x2 table frequencies (lower right cell).

    		 None
    n1i ArrayLike | str | None

    Group sizes or row totals (first group or row).

    		 None
    n2i ArrayLike | str | None

    Group sizes or row totals (second group or row).

    		 None
    x1i ArrayLike | str | None

    Number of events (first group).

    		 None
    x2i ArrayLike | str | None

    Number of events (second group).

    		 None
    t1i ArrayLike | str | None

    Total person-times (first group).

    		 None
    t2i ArrayLike | str | None

    		 None
    m1i ArrayLike | str | None

    		 None
    m2i ArrayLike | str | None

    Means (second group or time point).

    		 None
    sd1i ArrayLike | str | None

    Standard deviations (first group or time point).

    		 None
    sd2i ArrayLike | str | None

    Standard deviations (second group or time point).

    		 None
    xi ArrayLike | str | None

    Frequencies of the event of interest.

    		 None
    mi ArrayLike | str | None

    Frequencies of the complement of the event of interest, or the group means.

    		 None
    ri ArrayLike | str | None

    Raw correlation coefficients.

    		 None
    ti ArrayLike | str | None

    Total person-times or t-test statistics.

    		 None
    fi ArrayLike | str | None

    F-test statistics.

    		 None
    pi ArrayLike | str | None

    (Signed) p-values.

    		 None
    sdi ArrayLike | str | None

    Standard deviations.

    		 None
    r2i ArrayLike | str | None

    R^2 values.

    		 None
    mini ArrayLike | str | None

    Minimum values.

    		 None
    maxi ArrayLike | str | None

    Maximum values.

    		 None
    ni ArrayLike | str | None

    Sample or group sizes, as an array or column name. Passed to escalc for raw data; otherwise stored with the model (as its ni), and taken from an escalc frame when not given.

    		 None
    mods str | ArrayLike | DataFrame | None

    Moderators, as a one-sided formula string ('~ ablat + year'; needs data), a one-dimensional array (one moderator), a matrix or a data frame, with one row per study. None fits a model with no moderators.

    		 None
    measure str

    Effect size or outcome measure: 'GEN' (generic, the default, used with yi and vi) or any code of escalc ('SMD', 'OR', 'RR', 'RD', 'ZCOR', ...; with yi and vi it only labels the estimates). 'HR' and 'HD' are also accepted. Must be given when raw data are passed; an escalc frame supplies its own.

    		 'GEN'
    data DataFrame | None

    Data frame holding the variables named in the other arguments.

    		 None
    slab ArrayLike | str | Sequence[str] | None

    Study labels, as a sequence or a column name. Defaults to the labels stored by escalc, else 1, 2, ....

    		 None
    subset ArrayLike | str | None

    Which studies to fit: a boolean array, an array of 0-based indices, or a string expression evaluated on data.

    		 None
    add float | None

    Constant added to zero cells, counts or frequencies when effect sizes are computed from raw data (default 1/2, but 0 for the measures 'AS', 'PHI', 'ZPHI', 'RTET', 'ZTET', 'IRSD', 'PAS', 'PFT', 'IRS' and 'IRFT'). See escalc.

    		 None
    to Literal['all', 'only0', 'if0all', 'none']

    Which tables get add: 'only0' (those with a zero cell, the default), 'all', 'if0all' (all, if any table has a zero cell) or 'none'.

    		 'only0'
    drop00 bool

    Drop studies with no events (or only events) in both groups from the calculations (raw data only).

    		 False
    intercept bool

    Include an intercept when mods is a vector, matrix or data frame. Ignored when mods (or yi) is a formula. Without moderators an intercept is always included (intercept=False gives a warning).

    		 True
    method str | Sequence[str]

    Estimator of the amount of heterogeneity tau^2 (case-sensitive): 'EE', 'FE' or 'CE' (equal-, fixed- or common-effects model, tau^2 = 0), 'DL', 'DLIT', 'HE' (also 'CO' and 'VC'), 'HS', 'HSk', 'SJ', 'SJIT', 'ML', 'REML' (the default), 'EB', 'PM' (also 'MP'), 'PMM', 'GENQ' or 'GENQM'. A sequence is tried in order until one succeeds. Location-scale models need 'ML' or 'REML' (the first of a sequence is used).

    		 'REML'
    weighted bool

    Use inverse-variance weights (True) or ordinary least squares (False).

    		 True
    test str

    Test for the coefficients (case-insensitive): 'z' (normal, the default), 't' (t distribution with k - p degrees of freedom), 'knha' (Knapp-Hartung adjustment, with t and F distributions; alias 'hksj') or 'adhoc' (Knapp-Hartung, but the adjusted standard errors are never smaller than the unadjusted ones). With one study 'z' is used.

    		 'z'
    level float

    Confidence interval level in percent (95 is 95%). As in metafor, 0.95 is also read as 95% and 0.05 as an alpha of 0.05.

    		 95
    digits int | Mapping[str, int] | None

    Number of decimals used when printing, or a mapping with the keys est, se, ... (only est is used, else the first value). Stored in the result; None is 4.

    		 None
    btt int | Sequence[int] | str | None

    Coefficients to test jointly in the omnibus test, as 0-based indices or a regular expression matched against coefficient names (re.search). Printed output reports them 1-based, as metafor does. Default: all coefficients but the intercept (the intercept itself for a model without moderators).

    		 None
    att int | Sequence[int] | str | None

    Scale coefficients to test jointly, as btt. Location-scale models only; ignored with a warning otherwise.

    		 None
    scale str | ArrayLike | DataFrame | None

    Scale moderators of a location-scale model: a one-sided formula ('~ ni100', which includes an intercept unless 0 or -1 is given; needs data), or a matrix or data frame with one row per study, which is used as it is (no intercept column is added). Turns the model into a location-scale model.

    		 None
    link Literal['log', 'identity']

    Link function of the scale model, 'log' (the default) or 'identity'; anything else raises an error. Location-scale models only.

    		 'log'
    optbeta bool

    Estimate the location coefficients jointly with the scale coefficients (needs weighted=True). Location-scale models only; ignored with a warning otherwise.

    		 False
    alpha ArrayLike | None

    Fixed values for the scale coefficients (None or NaN entries are estimated; one number is used for all). Location-scale models only.

    		 None
    beta ArrayLike | None

    Fixed values for the location coefficients (None or NaN entries are estimated); used only with optbeta=True. Location-scale models only.

    		 None
    tau2 float | None

    Fixed value of tau^2 instead of estimating it (no effect for method='EE', 'FE' or 'CE'; ignored with a warning for location-scale models).

    		 None
    control Control | LSControl | Mapping[str, Any] | None

    Settings of the tau^2 estimation (tau2_init, tau2_min, tau2_max, threshold, tol, ll0check, maxiter, stepadj, evtol and REMLf), as a Control or a mapping with the same names as metafor (. becomes _). Names that only other metafor functions read are ignored; any other name raises an error. Location-scale models take an LSControl or a mapping instead.

    		 None
    verbose bool | int

    Print metafor's iteration log of the tau^2 estimators to stdout; 2 or more also prints progress messages to stderr. Location-scale models print only a blank line and, for 2 or more, the messages about extracting the data.

    		 False
    na_action Literal['omit', 'fail', 'pass']

    What to do with studies that have missing values (metafor uses the global na.action option instead): 'omit' (the default) leaves them out of the fit and 'fail' raises an error. 'pass' leaves them out of the fit too.

    		 'omit'
    vtype str | Sequence[str]

    Type of the sampling variance formula used by escalc for raw data, 'LS' by default; may be a sequence with one type per study.

    		 'LS'
    correct bool

    Bias correction of escalc for the measures that have one (True by default), for raw data only.

    		 True
    cutoff float | None

    Value above which the absolute value of an estimate computed by escalc is flagged with a warning. The default is 2 for 'SMD' and its variants and no check otherwise; NaN switches the check off.

    		 None
    onlyo1 bool

    Passed to escalc: add is added to the ai and ci cells of the 2x2 tables only, not to bi and di.

    		 False
    addyi bool

    Passed to escalc: True (the default) computes yi from the counts after add and to, False from the unadjusted counts.

    		 True
    addvi bool

    Passed to escalc: the same for the sampling variances vi.

    		 True
    knha bool | None

    True is the same as test='knha' and False the same as test='z'.

    		 None
    dfs float | Sequence[float] | None

    Degrees of freedom of the t and F tests (the first value is used) instead of k - p.

    		 None
    i2def Literal['1', '2']

    Definition of I^2 and H^2: '1' (the default), or '2' to use the typical sampling variance 1 / mean(1 / vi).

    		 '1'
    r2def str

    Definition of R^2 of a model with moderators: '1' (the default), '1v', '2', '2v', '3', '3v', '4', '4w', '5', '6', '7' or '8'.

    		 '1'
    skipr2 bool

    Skip the computation of R^2.

    		 False
    abbrev bool

    Shorten the names of the coefficients of factor(), poly(), relevel() and I() terms.

    		 False
    skiphes bool

    Skip the Hessian of location-scale models, so that their standard errors are missing.

    		 False

    Returns:

    Type Description
    RMAResult | RMALSResult

    The fitted model, an RMAResult (an RMALSResult when scale is given). Estimates are in beta, se, zval, pval, ci_lb and ci_ub; heterogeneity statistics in tau2, I2, H2, QE and QEp (arrays with one value per study for a location-scale model, except QE and QEp); summary() returns the printout as a string.

    Raises:

    Type Description
    InputError

    an argument or the data is invalid.
    ArgumentError

    control has a name that no function of metafor reads.
    NotFoundError

    a column name given for an argument is not in data.
    EstimationError

    every requested tau^2 estimator failed (including 'GENQ' without weights).

    Examples:

    >>> from metafopy import datasets, rma
>>> dat = datasets.load("dat.bcg")
>>> rma(measure="RR", ai="tpos", bi="tneg", ci="cpos", di="cneg", data=dat)

    Fit a Mantel-Haenszel meta-analysis of 2x2 tables (measure 'OR', 'RR', 'RD') or rate data ('IRR', 'IRD').

    Mirrors metafor's rma.mh(). The pooled effect is the Mantel-Haenszel estimate (Mantel & Haenszel, 1959; see metafor's help page for the further references). The individual effect sizes and sampling variances are computed as by escalc. For odds ratios the result also holds the Cochran-Mantel-Haenszel test and Tarone's test of heterogeneity, for incidence rate ratios the Mantel-Haenszel test. The first element of add, to and drop00 is used when computing the individual yi/vi values, the second one for the counts entering the Mantel-Haenszel estimator (by default nothing is added to them and no study is dropped there).

    Parameters:

    Name Type Description Default
    ai ArrayLike | str | None

    Frequencies of the 2x2 tables, upper left cell (event in group 1), as an array or the name of a column of data.

    		 None
    bi ArrayLike | str | None

    Frequencies of the 2x2 tables, upper right cell (no event in group 1).

    		 None
    ci ArrayLike | str | None

    Frequencies of the 2x2 tables, lower left cell (event in group 2).

    		 None
    di ArrayLike | str | None

    Frequencies of the 2x2 tables, lower right cell (no event in group 2).

    		 None
    n1i ArrayLike | str | None

    Size of group 1 (row total); can be given instead of bi.

    		 None
    n2i ArrayLike | str | None

    Size of group 2 (row total); can be given instead of di.

    		 None
    x1i ArrayLike | str | None

    Number of events in group 1 (rate data, 'IRR' and 'IRD').

    		 None
    x2i ArrayLike | str | None

    Number of events in group 2 (rate data).

    		 None
    t1i ArrayLike | str | None

    Total person-time of group 1 (rate data).

    		 None
    t2i ArrayLike | str | None

    Total person-time of group 2 (rate data).

    		 None
    measure str

    Effect measure: 'OR' (log odds ratio, the default), 'RR' (log risk ratio), 'RD' (risk difference), 'IRR' (log incidence rate ratio) or 'IRD' (incidence rate difference). Other measures raise an error.

    		 'OR'
    data DataFrame | None

    Data frame holding the variables named in the other arguments.

    		 None
    slab ArrayLike | str | Sequence[str] | None

    Study labels, as a sequence or a column name. Defaults to 1, 2, ....

    		 None
    subset ArrayLike | str | None

    Which studies to use: a boolean array, an array of 0-based indices, or a string expression evaluated on data.

    		 None
    add float | Sequence[float]

    Constant added to zero cells or counts. A single value, or a pair: the first applies when the yi/vi values of the studies are computed and the second to the counts entering the Mantel-Haenszel estimator. Default 0.5, which with a single value is used for the yi/vi values only (the second is then 0).

    		 0.5
    to str | Sequence[str]

    Which tables get add: 'all', 'only0' (those with a zero cell, the default), 'if0all' (all, if any table has a zero cell) or 'none'. A single value, or a pair as for add (the second is then 'none').

    		 'only0'
    drop00 bool | Sequence[bool]

    Drop studies with no events (or only events) in both groups. A single value, or a pair as for add (the second is then False). Default True.

    		 True
    correct bool

    Use the continuity correction in the Cochran-Mantel-Haenszel test (odds ratios) and in the Mantel-Haenszel test (incidence rate ratios).

    		 True
    level float

    Confidence interval level in percent (95 is 95%).

    		 95
    verbose bool | int

    Print metafor's progress messages to stderr (and blank lines to stdout).

    		 False
    digits int

    Number of decimals used when printing, stored in the result.

    Mirrors metafor's selmodel(). A selection model describes how the probability that an estimate is observed depends on its p-value (and optionally its precision); it is used to assess and adjust for publication bias (Vevea & Hedges, 1995; Citkowicz & Vevea, 2017; Preston, Ashby & Smyth, 2004).
