    Publication bias¶

    Tests and methods for publication bias and small-study effects, see Publication bias.

    regtest ¶

    Regression test for funnel plot asymmetry (metafor's regtest).

    Sterne & Egger (2005), doi:10.1002/0470870168.ch6 -- the test adds the standard error (or another measure of precision) as a predictor to the meta-analytic model. See https://wviechtb.github.io/metafor/reference/regtest.html.

    regtest ¶

    regtest(
    x: RMAResult | FixedBinaryResult | ArrayLike | str,
    vi: ArrayLike | str | None = None,
    *,
    sei: ArrayLike | str | None = None,
    ni: ArrayLike | str | None = None,
    subset: ArrayLike | None = None,
    data: DataFrame | None = None,
    model: Literal['lm', 'rma'] = 'rma',
    predictor: Literal[
        'sei', 'vi', 'ni', 'ninv', 'sqrtni', 'sqrtninv'
    ] = 'sei',
    ret_fit: bool = False,
    digits: int | None = None,
    level: float | None = None,
    method: str | None = None,
    test: str | None = None,
    na_action: Literal[
        'omit', 'exclude', 'pass', 'fail'
    ] = 'omit',
) -> RegtestResult

    Regression test for funnel plot asymmetry (Egger's test and extensions).

    Mirrors metafor's regtest. The effect sizes are regressed on a measure of their precision (the standard error by default) and the test for the coefficient of that predictor is the test for asymmetry (Egger et al., 1997, doi:10.1136/bmj.315.7109.629). With a fitted model that has moderators, the predictor is added to the model. The intercept of the model with sei, vi, ninv or sqrtninv as the predictor is the 'limit estimate' of the effect (the estimate under infinite precision), see RegtestResult.

    Parameters:

    Name Type Description Default
    x RMAResult | FixedBinaryResult | ArrayLike | str

    a fitted model (rma_uni result, or a fixed-effects rma_mh / rma_peto result with model='lm'; model='rma' raises for the latter two, as in metafor), or the observed effect sizes (array-like, or the name of a column of data).

    		 required
    vi ArrayLike | str | None

    sampling variances of a vector x (array-like or column name of data); ignored with a warning when x is a model.

    		 None
    sei ArrayLike | str | None

    standard errors, used when vi is not given.

    		 None
    ni ArrayLike | str | None

    sample sizes (array-like or column name of data), needed for the predictors based on ni. For a model it must have the length of the original data set and defaults to the sample sizes stored in the model. For a vector x it must have the length of x and defaults to the sample sizes stored by escalc.

    		 None
    subset ArrayLike | None

    0-based integer indices or boolean mask of the studies to use (vector input only).

    		 None
    data DataFrame | None

    data frame in which string values of x, vi, sei and ni are looked up as column names.

    		 None
    model Literal['lm', 'rma']

    'rma' | 'lm'. 'rma' (default) fits a meta-regression model (a mixed-effects model for a random-effects x), 'lm' the weighted regression with multiplicative dispersion (the classical Egger test).

    		 'rma'
    predictor Literal['sei', 'vi', 'ni', 'ninv', 'sqrtni', 'sqrtninv']

    'sei' | 'vi' | 'ni' | 'ninv' | 'sqrtni' | 'sqrtninv': the standard error (default), the sampling variance, the sample size, its inverse, its square root or the inverse of its square root. The last four need ni.

    		 'sei'
    ret_fit bool

    whether the printed summary also shows the fitted regression model (fit is in the result either way). It prints nothing extra for model='lm', which has no fit.

    		 False
    digits int | None

    number of decimals used when the result is printed. Default None: the digits of the model, or 4.

    		 None
    level float | None

    confidence level of the interval of the limit estimate and of the model fit, between 0 and 100 (as in metafor's level: 95 or 0.95 give a 95% interval, and a value up to 0.5 is read as the significance level). Default None: the level of the model, or 95.

    		 None
    method str | None

    tau^2 estimator of the meta-regression model, e.g. 'REML', 'DL' or 'FE'. Default None: the method of x, or 'REML' for a vector. For model='lm' it is only recorded in the result.

    		 None
    test str | None

    test for the model coefficients: 'z' | 't' | 'knha' | 'adhoc'. Default None: the test of x, or 'z' for a vector. Ignored for model='lm', which always uses a t-test.

    		 None
    na_action Literal['omit', 'exclude', 'pass', 'fail']

    what to do with studies with missing values in a vector x: 'omit' | 'exclude' | 'pass' omit them with a warning, 'fail' raises. It has no effect on a fitted model.

    		 'omit'

    Returns:

    Type Description
    RegtestResult

    A RegtestResult with the test statistic zval, its p-value pval, the degrees of freedom ddf (None for
    RegtestResult

    a z-test), the limit estimate est with its confidence interval ci_lb, ci_ub (only when predictor is 'sei', 'vi', 'ninv' or
    RegtestResult

    'sqrtninv' and the model has no moderators, else None), and the regression model fit (None for model='lm').

    Raises:

    Type Description
    InputError

    an argument or the data is invalid, or studies are missing and na_action='fail'.
    NotSupportedError

    x is a model of a class regtest is not available for (for example rma_mv, rma_glmm, rma_ls, selection models and robust fits).
    EstimationError

    the tau^2 estimator of the regression model fails.

    ranktest ¶

    Rank correlation test for funnel plot asymmetry (metafor's ranktest).

    Begg & Mazumdar (1994), doi:10.2307/2533446. Kendall's tau between the standardised estimates and their sampling variances; the p-value follows R's cor.test(method='kendall'): exact (the default, exact=True) when there are no ties, a normal approximation otherwise. See https://wviechtb.github.io/metafor/reference/ranktest.html.

    Rank correlation test for funnel plot asymmetry (Begg and Mazumdar, 1994).

    Mirrors metafor's ranktest. Kendall's rank correlation between the standardized effect sizes and their sampling variances is computed (Begg & Mazumdar, 1994, doi:10.2307/2533446). A significant correlation indicates funnel plot asymmetry.

    Parameters:

    Name Type Description Default
    x RMAResult | RMAMVResult | FixedBinaryResult | RMALSResult | SelmodelResult | GLMMResult | ArrayLike | str

    a fitted model without moderators (its effect sizes and sampling variances are used), or the observed effect sizes (array-like, or the name of a column of data).

    		 required
    vi ArrayLike | str | None

    sampling variances of a vector x (array-like or column name of data); ignored with a warning when x is a model.

    		 None
    sei ArrayLike | str | None

    standard errors, used when vi is not given. One of vi and sei is required for a vector x.

    		 None
    subset ArrayLike | None

    0-based integer indices or boolean mask of the studies to use (vector input only).

    		 None
    data DataFrame | None

    data frame in which string values of x, vi and sei are looked up as column names.

    		 None
    digits int | None

    number of decimals used when the result is printed. Default None: the digits of the model, or 4.

    		 None
    exact bool

    whether the exact p-value is computed (default True; metafor takes this argument from ...). The exact p-value needs untied observations; with ties, or if the exact p-value cannot be computed, the normal approximation is used.

    		 True
    na_action Literal['omit', 'exclude', 'pass', 'fail']

    what to do with studies with missing values in a vector x: 'omit' | 'exclude' | 'pass' omit them with a warning, 'fail' raises. It has no effect on a fitted model.

    		 'omit'

    Type Description

    Type Description

    trimfill ¶

    trimfill(
    x: RMAResult,
    side: Literal['left', 'right'] | None = None,
    estimator: Literal['L0', 'R0', 'Q0'] = 'L0',
    maxiter: int = 100,
    verbose: bool = False,
    ilim: tuple[float, float] | None = None,
    **kwargs: Any,
) -> TrimfillResult

    Trim-and-fill method for a model without moderators.

    Mirrors metafor's trimfill. The number of studies missing from one side of the funnel plot is estimated (Duval & Tweedie, 2000, doi:10.1111/j.0006-341X.2000.00455.x), the corresponding mirror-image studies are filled in, and the model is refitted to the observed and the filled-in studies.

    Parameters:

    Name Type Description Default
    x RMAResult

    a fitted equal- or random-effects model (rma_uni result) without moderators.

    		 required
    side Literal['left', 'right'] | None

    'left' | 'right': the side of the funnel plot on which studies are missing. Default None: determined from the sign of the slope of a regression of the effect sizes on their standard errors (the 'right' side if it is negative).

    		 None
    estimator Literal['L0', 'R0', 'Q0']

    'L0' | 'R0' | 'Q0': the estimator of the number of missing studies (default 'L0').

    		 'L0'
    maxiter int

    maximum number of iterations of the algorithm (default 100); an error is raised when it does not converge.

    		 100
    verbose bool

    whether to print the iterations (number of missing studies and estimate) to stdout.

    		 False
    ilim tuple[float, float] | None

    (lower, upper) limits to which the effect sizes of the augmented data set are clipped; as in metafor's code this includes the observed effect sizes as well as the filled-in ones, and it is only applied when studies are filled in. Must have two elements. Default None: no clipping.

    		 None
    **kwargs Any

    level and test are passed on to the model fits; other keywords are ignored (metafor passes all extra arguments to rma.uni).

    		 {}

    Returns:

    Type Description
    TrimfillResult

    A TrimfillResult: the refitted model (all the attributes of an RMAResult) with the
    TrimfillResult

    additional fields fill (flags the filled-in studies, which come last), k0, se_k0, side, k0_est and p_k0. If no study is
    TrimfillResult

    missing (k0 == 0) the model is that of x.

    Raises:

    Type Description
    InputError

    an argument or the data is invalid, x has moderators, k = 1, or the algorithm fails or does not converge.
    ArgumentError

    x is not an rma_uni result (for example an rma_mh result or a vector).
    NotSupportedError

    x is a robust fit, a location-scale model or a selection model.

    Fail-safe N calculation.

    Mirrors metafor's fsn. It computes the number of studies averaging a null result that would have to be added to a set of studies to reduce the significance level to a target value (or the average effect to a target size). The approaches (type) are Rosenthal's (1979, doi:10.1037/0033-2909.86.3.638), Orwin's (1983, doi:10.3102/10769986008002157), Rosenberg's (2005, doi:10.1111/j.0014-3820.2005.tb01004.x), a general approach that refits a random-effects model, and 'Binomial'. 'Binomial' is not on metafor's help page, but metafor's code (R/fsn.r, also in 5.2-1) has it: it takes the number of studies with a positive estimate, applies the two-sided exact binomial (sign) test of a probability of 0.5 and adds studies in pairs, one with a positive and one with a non-positive estimate, until the p-value reaches alpha; the fail-safe N is the number of studies added (0 if the observed p-value is already at least alpha).

    amount of heterogeneity in the true effects; the power of each study is then averaged over a normal distribution of the true effects with mean theta and variance tau2. Default None: homogeneous true effects. A value not above tau2_lb counts as none.

    		 None
    test Literal['chi2', 'binom', 'exact'] | None

    'chi2' | 'binom' | 'exact': the test of excess significance (chi-square, binomial or exact test). Default None: 'exact' if the number of terms in the sum of the exact test, the sum of the binomial coefficients choose(k, j) over the j involved (all j for tes_alternative='two.sided', j >= O for 'greater', j <= O for 'less'), is at most 10^6, else 'chi2'. The exact test is computed here without listing the combinations, so test='exact' also works for a large number of studies, where metafor stops.

    		 None
    tes_alternative Literal['two.sided', 'greater', 'less']

    'two.sided' | 'greater' | 'less': the alternative of the test of excess significance (default 'greater').

    		 'greater'
    tes_alpha float

    significance level of the test of excess significance, used for theta_lim (default 0.1).

    		 0.1
    progbar bool

    whether to show a progress bar on stderr during the exact test (metafor's default is True, here it is False).

    		 False
    digits int | None

    number of decimals used when the result is printed. Default None: the digits of the model, or 4.

    		 None
    correct bool

    whether the continuity correction of the chi-square test is used (default False).

    		 False
    rel_tol float

    tolerance (absolute and relative) of the numerical integration of the power over the distribution of the true effects (default eps**0.25).

    		 EPS ** 0.25
    subdivisions int

    		 100
    tau2_lb float

    tau2 values not above this lower bound are treated as zero (default 0).

    		 0.0
    find_lim bool

    whether theta_lim is estimated (default True; only when theta is a single value or estimated).

    		 True
    na_action Literal['omit', 'exclude', 'pass', 'fail']

    what to do with studies with missing values in a vector x: 'omit' | 'exclude' | 'pass' omit them with a warning, 'fail' raises. It has no effect on a fitted model.

    		 'omit'
