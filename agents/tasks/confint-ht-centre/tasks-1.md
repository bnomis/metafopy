# Tasks: confint type "ht" centre

**Source:** TODO.md, "confint type "ht" of a REML fit centres on the fit's H2, not on H from Q"
**Created:** 2026-11-14
**Version:** 1

The user answered *follow the reference* on 2026-11-12 (`agents/specs/correctness-tests/mismatches.md`, Answers, decision "the `ht` interval under
REML"), so this list changes metafopy's output without a new review.

Checked against the code on 2026-11-14 (metafopy at `1bd2712`): the `ht` branch of `confint` in `src/metafopy/methods/confint.py` builds the H2 bounds
as `math.exp(math.log(x.H2) -/+ crit * 2 * se_lnH)`, while `se_lnH` already comes from `x.QE` and `k`. Higgins and Thompson (2002, section 4.1.1 and
Appendix, method III) and Borenstein et al. (2009, equations 16.14 to 16.19) centre on `ln H` with `H^2 = Q / (k - 1)`. On `dat.bcg` log risk
ratios, replacing `x.H2` by `x.QE / (k - 1)` in those two lines (measured on a scratch copy) gives the tau2 interval 0.19972 to 0.47038 for every
method (`REML`, `DL`, `ML` and `PM` checked), which is the reference; before the change only `DL` gives it, because only for `DL` is the fit's `H2`
equal to `Q / (k - 1)`. The estimate column (the fit's `tau2`, `tau`, `I2`, `H2`) does not change. R metafor 5.2-1 centres on `log(x$H2)`, so for
every method other than `DL` metafopy will now differ from metafor: this list records that difference and opens the `docs/differences.md`
section "Where metafor departs from its reference", which `agents/tasks/qe-no-intercept/tasks-1.md` adds to later.

The project has no affected-tests tool, so each task names its test files, and the last task runs the test files that import `confint`, and
`src/tests/correctness`.
