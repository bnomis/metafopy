# Correctness tests

**Version:** 1.1
**Status:** proposed
**Date:** 2026-11-11

Every numeric test in `src/tests/` today compares metafopy with R metafor: the JSON fixtures in `src/tests/reference/` are written by `src/tests/r/*.R`, and
`bin/metafor-audit.sh` diffs the whole API against R. Those tests prove that metafopy reproduces metafor, not that either is right; a bug in metafor passes
them. This spec adds a second, independent layer: tests whose expected values come from the publications that define each method, from formulas re-derived
independently of metafopy's code, from properties theory guarantees, and from other software. **Correctness comes first, metafor compatibility second**
(decided 2026-11-11, recorded in `NOTES.md`): where metafopy matches metafor but not the defining reference, the reference wins once the user has confirmed
the case.

This first spec builds the harness and covers the core: `escalc` effect sizes and sampling variances, `rma_uni` heterogeneity estimators and inference,
`rma_mh` and `rma_peto`. Later specs extend the same harness to `rma_mv`, `rma_glmm`, `rma_ls`, the bias methods, `selmodel` and `robust`.

## Module location

- `src/tests/correctness/` - the suite (a test package, collected by the existing `testpaths = ["src/tests"]`).
  - `cases.py` - case-file loader and comparison helpers (API below).
  - `formulas.py` - independent re-derivations; imports `numpy` and `scipy` only, never `metafopy`.
  - `cases/*.toml` - the case catalogue, one file per area: `escalc.toml`, `tau2.toml`, `inference.toml`, `heterogeneity.toml`, `mh_peto.toml`.
  - `test_published.py`, `test_derived.py`, `test_properties.py`, `test_simulation.py`, `test_other_software.py` - one module per kind of evidence.
  - `test_coverage.py` - the scope gate and the harness's own checks.
  - `r/other_software.R` - generator of the other-software values.
- `agents/specs/correctness-tests/mismatches.md` - the review document of disagreements (see Mismatches).
- Edits: `claude/rules/metafopy.md`, `AGENTS.md`, `docs/differences.md`, `src/audit/data/known.toml` (only for confirmed mismatches).

## Kinds of evidence

Each case declares one `kind`, ranked by strength:

| Kind | Expected value comes from | Tolerance |
|---|---|---|
| `published` | A number printed in the defining paper or a textbook worked example | Half a unit in the last printed digit, derived from the value written as a string (`"0.0193"` gives `5e-5`) |
| `derived` | `formulas.py`, coded from the publication's equations, not from metafopy or metafor source | `rtol=1e-10` closed form; `1e-8` for iterative estimators |
| `property` | An identity, invariance, limiting case or estimating equation theory guarantees | Stated per case, default `1e-8` |
| `simulation` | A seeded Monte Carlo check of a result that is exact in theory | A binomial or normal bound at 4 standard errors, stated per case |
| `other` | An independent implementation (R `meta`), generated by `r/other_software.R` | `rtol=1e-6` |

Scope rule: every item in the coverage list (below) needs at least one `published` or `derived` case; `property`, `simulation` and `other` add to them
but never satisfy the gate alone, because a property can hold for a wrong estimator and other software can share metafor's mistakes.

Simulation cases assert only what holds exactly, not asymptotic behaviour: unbiasedness of the untruncated DL and HE estimators; unbiasedness of Hedges' `g`
with the exact `J` correction; exact coverage of the equal-effects CI with known `vi`. Low coverage of a Wald random-effects CI for small `k` is a known
property of the method, not a bug, and is not tested. Simulations use `numpy.random.default_rng(seed)` (they test methods, not ported randomised procedures,
so the R-exact `metafopy.core.rng` rule does not apply) and carry the existing `slow` marker; CI already runs them.

## Case file format

```toml
[[case]]
id = "tau2.dl.normand1999"           # unique; letters, digits, '.', '-', '_'
kind = "published"
function = "rma_uni"                 # a public metafopy callable
dataset = "dat.normand1999"          # metafopy.datasets.load name, or inline [case.data]
setup = { escalc = { measure = "MD", m1i = "m1i", sd1i = "sd1i", n1i = "n1i", m2i = "m2i", sd2i = "sd2i", n2i = "n2i" } }
args = { method = "DL" }
expect = { tau2 = "684", beta = "-15.106" }   # strings for published; floats for other kinds
status = "pass"                      # "pass" or "mismatch"
reason = ""                          # required when status = "mismatch"

[case.source]
citation = "Normand SL (1999). Meta-analysis: formulating, evaluating, combining, and reporting. Statistics in Medicine 18:321-359."
doi = "10.1002/(SICI)1097-0258(19990215)18:3<321::AID-SIM28>3.0.CO;2-P"
locator = "Table IV"                 # page, table, equation or section
read = "2026-11-12"                  # date the value was read from the source
```

The values above illustrate the format only; every real value is read from its source when the case is written. `expect` keys name result attributes
(`tau2`, `beta`, `se`, `ci_lb`, `QE`, `I2`, `yi`, `vi`, ...), indexed with `[i]` for vectors (`"yi[0]"`, 0-based as everywhere in metafopy).

## API

```python
@dataclasses.dataclass(frozen=True)
class Source:
    """Where a case's expected values come from: citation, DOI or URL, locator in the source, date read."""

    citation: str
    locator: str
    read: datetime.date
    doi: str | None = None
    url: str | None = None


@dataclasses.dataclass(frozen=True)
class Case:
    """One correctness case from a ``cases/*.toml`` file."""

    id: str
    kind: typing.Literal['published', 'derived', 'property', 'simulation', 'other']
    function: str
    args: dict[str, typing.Any]
    expect: dict[str, str | float]
    status: typing.Literal['pass', 'mismatch']
    source: Source | None
    dataset: str | None = None
    data: dict[str, list[float]] | None = None  # inline columns, instead of a dataset
    setup: dict[str, typing.Any] | None = None
    reason: str = ''
    tolerance: float | None = None
    check: str | None = None
    covers: tuple[str, ...] = ()  # the coverage items the case checks (see Coverage list)
    file: str = ''  # the case file, for messages


def load_cases(kind: str | None = None, *, directory: pathlib.Path | None = None) -> list[Case]:
    """Read every ``cases/*.toml`` file, validate each case, and return them (filtered by ``kind``)."""


def run_case(case: Case) -> typing.Any:
    """Load the dataset, apply ``setup`` (an ``escalc`` call), and call ``metafopy.<function>(**args)``."""


def published_tolerance(expected: str) -> float:
    """Half a unit in the last printed digit of ``expected`` (``'0.0193'`` -> ``5e-05``; ``'684'`` -> ``0.5``)."""


def check_case(case: Case, result: typing.Any) -> None:
    """Compare each ``expect`` key with the result at the kind's tolerance; raise AssertionError naming case, key, both values and the source."""


def case_params(kind: str) -> list[pytest.param]:
    """Cases of one kind as pytest params, id = case id; a ``mismatch`` case is marked ``xfail(strict=True, reason=...)``."""
```

A `derived` case's `expect` value is a float or `"formulas.<name>"`, a function called with the arguments of the case that it declares (a column name
replaced by the column). A case lists in `covers` the coverage items it checks, such as `escalc.yi.RD`, `escalc.vi.RD.LS`, `tau2.DL`, `test.knha`,
`confint.pl`, `predict.pi`, `heterogeneity.I2`, `rma_mh.OR.estimate`, `rma_mh.OR.variance` or `rma_peto`; the gate counts only the `covers` of `published`
and `derived` cases. `load_cases` takes a `directory` keyword for tests of the harness, and `[[exempt]]` entries (`item`, `reason`) and the `escalc` `vtypes`
table (a `vtypes` array of `{ measure, vtype = [...] }`, the same data as `[[vtypes]]` entries) are read by `load_exemptions` and `load_vtypes`.

`derived` and `property` cases whose check is not a single call carry `function = "formulas.<name>"` or a test-module function named in `check`; the
loader resolves both and refuses anything else.

## Coverage list

`test_coverage.py` fails unless each item has a `published` or `derived` case with `status = "pass"` or `"mismatch"`, or an `[[exempt]]` entry in its
case file with a reason (for example, a measure whose defining paper gives no formula):

- every `measure` in `metafopy.effects.measures.MEASURES`, read at test time, for `yi` and for `vi` with each `vtype` it accepts. The code has no
  per-measure `vtype` table, so `escalc.toml` holds one (`[[vtypes]]` entries of a measure and its accepted `vtype` values, from the `escalc` docstring
  and metafor's documentation; decided 2026-11-11); a test checks that `escalc` accepts every listed pair, and the gate needs a case or exemption
  for each;
- every `rma_uni` `method` in `metafopy.models.tau2.ESTIMATORS`, read at test time (the equal-effects methods included);
- `rma_uni` inference: every value of the `metafopy.models.rma_uni.Test` alias and every `confint` `type` for `tau2` in
  `metafopy.methods.confint.CIType`, both read at test time;
  `predict` prediction intervals;
- heterogeneity statistics: `QE`, `QM`, `I2`, `H2`;
- `rma_mh` for `OR`, `RR`, `RD`, `IRR`, `IRD` (estimate and variance) and `rma_peto`.

Reading the lists from the code means a newly ported option fails the gate until it has a case.

## Mismatches

A case whose reference disagrees with metafopy is committed with `status = "mismatch"` and a `reason` naming both values, so it runs as strict xfail: the
suite stays green, and the xfail turns into a failure the moment metafopy changes to agree. The case also goes into `mismatches.md`, a review document
(per the shared `reviews.md` rule) with an interactive page, one item each: the source and locator, the reference value, metafopy's and metafor's values,
and the options *follow the reference*, *keep metafor (reference misread or a different, valid convention)* or *investigate*. metafopy's output changes only
after the user's answer. Divergent conventions that are not errors (a different but published variance approximation) are not mismatches: the case pins
the convention metafor documents, and its source says which.

For each confirmed *follow the reference* answer, a follow-up change (not part of this spec's tasks): fixes metafopy; flips the case to `pass`; marks the
affected R parity fixtures with the reason; adds a `known.toml` entry so `bin/metafor-audit.sh` accepts the difference; and adds a section to
`docs/differences.md` under a new heading "Where metafor departs from its reference".

## Error handling

- A malformed case file (missing key, unknown `kind`, duplicate `id`, invalid id characters, `published` value not a string, `mismatch` without `reason`,
  missing `source` for `published`/`other`) raises `ValueError` naming the file and case id; `test_coverage.py` loads every file so it fails at once.
- An unknown `function`, dataset or `expect` attribute fails that case with the name it could not resolve.
- `formulas.py` importing `metafopy` (directly or by any `import metafopy...`) fails `test_coverage.py`, checked with `ast`.
- `r/other_software.R` stops with an error unless `packageVersion("meta")` equals the version pinned at its top, and writes that version and R's into each
  generated case's `source`.

## Implementation

1. Harness: `cases.py`, `test_coverage.py` (scope gate, file validation, `formulas.py` import check), with two worked cases to prove it end to end.
2. `formulas.py` from the publications: every `escalc` measure's `yi` and `vi`; DL, HE, HS, HSk, SJ closed forms; the PM, EB, ML and REML estimating
   equations (the `derived` check solves them with `scipy.optimize.brentq`, independently of metafopy's iterations); Q, I2, H2; KH variance; MH and Peto.
3. Published cases from the seed sources, fetched and recorded one source at a time.
4. Property cases: location and scale invariance of `tau2` and `beta`; `tau2 = 0` estimators giving the equal-effects fit; estimating equations at
   metafopy's optimum (REML score zero, PM `Q(tau2) = k - 1`); `I2 = (H2 - 1) / H2`.
5. Simulation cases (`slow`).
6. Other-software cases from `r/other_software.R`, run with `LC_ALL=C.UTF-8 Rscript` against an R library outside the repository named by
   `METAFOPY_CORRECTNESS_RLIB` (R `meta` is not in the audit's pinned library in `src/audit/data/r-versions.json`, and this spec does not change that pin).
   The generated values are committed; tests never run R.
7. Rules: amend `claude/rules/metafopy.md` ("R metafor is the oracle: port numerics line for line") to say the defining reference outranks metafor, and
   R parity is the second check; amend `AGENTS.md` "R metafor is the numeric oracle" the same way.
8. `mismatches.md` and its review page; work stops until each mismatch has an answer.

## External dependencies

- `numpy`, `scipy`, `pytest` (existing); `tomllib` (standard library).
- R `meta` in a separate library for step 6 only; its version is pinned in the generator script.
- Source access through the connected literature tools; paywalled sources from the user.
