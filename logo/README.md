# metafopy logo

Mark: a Baujat-plot cluster of six studies plus one influential study (the ball), in a white rounded box with a hairline graphite border.

| Element | Value |
|---|---|
| Box | white #FFFFFF, corner radius 40/180 of the side, border graphite #3D3F44, 0.5 px at 180 px |
| Dots ([Solarized](https://ethanschoonover.com/solarized/) accents) | orange #CB4B16, green #859900, blue #268BD2, yellow #B58900, violet #6C71C4, cyan #2AA198 |
| Ball | Solarized red #DC322F |
| Wordmark | Source Serif 4 Display Semibold ([Adobe, OFL](https://github.com/adobe-fonts/source-serif)), graphite #3D3F44, converted to outlines |

## Files

- `svg/metafopy-logo.svg`: mark and wordmark (text outlined, no font needed)
- `svg/metafopy-mark.svg`: mark only
- `svg/metafopy-mark-animated.svg`, `png/metafopy-mark-animated-256.gif`: the dots bounce, slow down and settle, hold 4 s, then loop
- `png/`: mark at 64 to 1024 px, logo at 1x/2x/4x (transparent background)
- `favicon/`: `favicon.svg`, `favicon.ico` (16/32/48), `favicon-{16,32,48}.png`, `apple-touch-icon.png` (180 px)
- `favicon/favicon-animate.js`: tab icon whose large dot fades slowly between Solarized accents (Chrome, Edge, Firefox; Safari keeps the static icon).
  Open `favicon/favicon-demo.html` in a browser to try it.

## Rebuild

Everything except `favicon-animate.js` and `favicon-demo.html` is generated by `bin/logo.py`. It needs the font
(`SourceSerif4Display-Semibold.otf` from a [source-serif release](https://github.com/adobe-fonts/source-serif/releases)) and headless Chromium.
Its dependencies (fonttools, uharfbuzz, Pillow) are declared inline ([PEP 723](https://peps.python.org/pep-0723/)), not in `pyproject.toml`:

```sh
uv run --script bin/logo.py --font SourceSerif4Display-Semibold.otf --chrome /path/to/chromium
```
