# Plots compared with metafor

Every plot of the [plot gallery](guide/gallery.md) drawn by metafopy and by R metafor 5.2-1 (side by side on wide screens), from the code of the
corresponding page of the [metafor plot gallery](https://www.metafor-project.org/doku.php/plots). The code of each figure is in the
gallery; the link under each pair leads to it.

The two renderings agree in the geometry of what is drawn (positions, sizes, labels). They differ in details of the rendering such as
the font, which is Helvetica or Arial in R and DejaVu Sans in matplotlib by default.
